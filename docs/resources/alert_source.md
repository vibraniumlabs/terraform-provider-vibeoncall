# vibeoncall_alert_source (Resource)

An alert source: the webhook URL, or inbound email address, a monitoring tool sends alerts to. Each alert that arrives is handed to the source's alert routing.

~> **Note** Every read returns the webhook token, so the API key needs the `alertSource.manage` permission even to plan or refresh this resource.

Changing `type` or `team_id` replaces the source, and the new source has a new `webhook_url`. Set `create_before_destroy`, as in the example, so the old URL keeps accepting alerts until the monitoring tool's configuration, referencing `webhook_url`, moves to the new one.

## Example Usage

```terraform
resource "vibeoncall_alert_source" "datadog" {
  name    = "Datadog production"
  type    = "datadog"
  team_id = vibeoncall_team.payments.id

  lifecycle {
    create_before_destroy = true
  }
}

# Hand the webhook URL to the monitoring tool's own provider.
resource "datadog_webhook" "vibeoncall" {
  name      = "vibeoncall-payments"
  url       = vibeoncall_alert_source.datadog.webhook_url
  encode_as = "json"
}
```

## Schema

### Required

- `name` (String) Source name, unique among sources of the same `type` in the same scope: the same team, or organization level.
- `type` (String) The monitoring tool that sends to this source, such as `datadog`, `grafana`, `http` or `email`. Changing it replaces the source, which gives it a new webhook URL.

### Optional

- `alert_routing_id` (String) Numeric ID of the alert routing that handles alerts arriving on this source. It must belong to the same team as the source, or be organization-level for an organization-level source.
- `enabled` (Boolean) Whether the source accepts alerts. A disabled source rejects what arrives on it. Defaults to `true`.
- `team_id` (String) Numeric ID of the team the source belongs to. Omit for an organization-level source. Changing it replaces the source, which gives it a new webhook URL.

### Read-Only

- `email_address` (String) Inbound address of an `email` source. Null for every other type.
- `id` (String) Numeric alert source ID.
- `webhook_token` (String, Sensitive) Secret token at the end of `webhook_url`, for tools that take the token separately. Null for an `email` source.
- `webhook_url` (String, Sensitive) URL the monitoring tool posts alerts to. Null for an `email` source.
