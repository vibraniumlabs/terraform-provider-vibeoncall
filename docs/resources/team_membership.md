# vibeoncall_team_membership (Resource)

A member's place on a team.

~> **Note** If the user is already on the team, creating this resource takes over that membership and sets `role`, which defaults to `member`. The plan shows a create, not the role change. To review the change first, import the membership and run `terraform plan`.

~> **Note** Don't use this resource on a team that sets `members` on `vibeoncall_team`; the team would remove this membership on its next apply.

## Example Usage

```terraform
data "vibeoncall_member" "ada" {
  email = "ada@example.com"
}

resource "vibeoncall_team_membership" "ada" {
  team_id = vibeoncall_team.sre.id
  user_id = data.vibeoncall_member.ada.id
  role    = "admin"
}
```
